## Judgement calls

- Example-leak recheck: 50 old examples (batches 1-2, sample) and some new ones were rewritten because they contained another A1 answer as a whole word (e.g. "swim", "farm", "station", "left", "baby", "coat"). Clues/answers unchanged. Script check across all A1 files now reports 0 collisions.
- TAXI is a CONTAINS-X card (letter X, difficulty 1) to give X a 5th card; Q still 3 (no official A1 Q word).
- Numbers/days/months use direct translations ("üç", "salı", "cumartesi"); MARCH/MAY are months (clue "yılın üçüncü/beşinci ayı") - could also be read as verb/modal, review.
- LEFT/RIGHT clues ("sağın zıddı yön" / "solun zıddı yön") are mutually referencing; RIGHT could also fit "doğru". pos adv matches "Turn left here."
- SEA vs existing OCEAN ("deniz" vs "okyanus"); TOWN ("şehirden küçük yerleşim") vs CITY; BATH vs SHOWER; EASY/DIFFICULT use "zor olmayan"/"kolay olmayan"; BEAUTIFUL vs NICE differ by letter.
- Likely A2 in some lists (included for letter balance U/V/Y/K/E): VIOLIN, VOICE, UNIVERSITY, YOGURT, KNEE, HOBBY, GUITAR, FRIDGE, SEPTEMBER-type months are A1 in most lists.
- Spelling choices: GREY and COLOUR (British), MOVIE (also accepted American); EMAIL as one word.
- GO (2 letters) allowed by schema; clue "gitmek".
- Categories: no clothes/nature/music at A1, so COAT/SKIRT/LAKE/SEA/GUITAR/VIOLIN etc. are `daily-life`; PEOPLE/BABY/PARENTS in `family-people`.
- Compiler: 0 errors; only the existing A2 warning.
