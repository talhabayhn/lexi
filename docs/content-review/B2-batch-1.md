# B2 batch 1 review (letters A, B; phrasal verbs and idioms included)

File `content/cards/B2/batch1.csv`. B2 mix: regular vocabulary, phrasal verbs (pos `phrasal`, category `phrasal-verbs`) and idioms (pos `idiom`, category `idioms`). Categories limited to those B2 supports in `categories.csv`. Answers also avoid every A1/A2/B1 answer and the C1/NAT smoke sets. American spelling follows the B2 smoke set only where it already exists (RECOGNIZE); new cards use British spelling.
Reviewer drops: BY THE WAY (A2 discourse phrase), BUREAUCRACY, BLUEPRINT, BRIBE, BYSTANDER, ALLIANCE, ACCOUNTABLE, BREAKTHROUGH (C1+). Clues/examples: BOUNDARY (vs BORDER), BUILD UP (vs BOOST), ACKNOWLEDGE (vs ADMIT/ACCEPT), ARISE, BLOW UP, ASSURE.
Doubtful level (maybe B1 or C1): APPEAL, ASPECT, AUTHORITY, BIAS, BROADEN, BURDEN.
