## 7. Engine card selection (facts)

- `difficulty` is validated (1-5), stored in content.db and mapped onto `Card`, but no selection code reads it.
- `WheelGenerator.generate` filters the pool by `level` (and category); the category fallback also stays in the same level; a letter with no card is SKIPPED, never filled from another level.
- Pick = candidates sorted by id -> not recently seen -> STARTS preferred (`preferStarts`) -> never-seen, else least-recently-seen -> one seeded `nextInt`.
- Cross-level by design: Daily (`WheelGenerator.daily`, A1x6 A2x5 B1x5 B2x4 C1x3 NAT x3), review wheel (due notebook cards of any level), exam packs (any level), level test (adaptive, moves up/down a level).
- Solo wheels and Duel (`wheelPool(level)`) are single-level.
- So an easy-first selection needs a new difficulty rule in `pickFresh`/`preferStarts`; today d1..d3 cards of a letter are equally likely.
