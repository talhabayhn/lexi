# B2 batch 8 review (hard letters Q, X, Y, Z)

File `content/cards/B2/batch8.csv`. Almost all CONTAINS cards (deliberate hard-letter exception): Q (QUALIFIED and QUOTA are the only STARTS cards), X, Y and Z. Spelling policy: -ISE/-IZE variants of an answer already in A2/B1 are not repeated (ORGANISE, CRITICISE, APOLOGISE, ENQUIRE exist), so those -IZE twins were dropped; the remaining -IZE words (SPECIALIZE, UTILIZE, MAXIMIZE, MINIMIZE, PRIORITIZE, VISUALIZE, ENERGIZE, SYMPATHIZE, PRIVATIZE, STABILIZE) follow the existing B2 RECOGNIZE.
Reviewer drops: INQUIRE, EXTREMELY, WEEKLY (A2/duplicates), ELOQUENT, SIZEABLE (rare). Category: EQUALLY.
Gaps: Q 11, Y 13, Z 11 after drops (target 20); true B2 words for these letters are scarce.
Doubtful level (maybe C1): SUBSEQUENT, ACQUAINTANCE, EXPERTISE, CONSISTENCY, STABILIZE, PRIVATIZE.
