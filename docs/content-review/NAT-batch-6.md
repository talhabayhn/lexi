File `content/cards/NAT/batch6.csv` (113 cards). Hard letters use CONTAINS cards: W AWRY, ERSTWHILE, BELLWETHER, UNWIELDY, OVERWROUGHT, NEWFANGLED; X all CONTAINS (EX- words, OBNOXIOUS, LAX, VEXED, CRUX, HOAX, MAXIM, FLUX, OXYMORON, DEXTERITY, PERPLEX, ANNEX); Y only YARDSTICK and YOKE start with Y; Z STARTS ZANY, ZEITGEIST, ZEST, the rest CONTAINS. -IZE spellings (GALVANIZE, LIONIZE, OSTRACIZE, TANTALIZE, PATRONIZE, MESMERIZE) are kept for Z coverage, as in C1.
