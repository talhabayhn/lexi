Notes on **?** items:
- TOOTH / FOOT: "(tekil)" added so TEETH / FEET (same first letter) are ruled out. Alternative: plain "diş" / "ayak".

- VERY: "çok" alone; on the V letter no other common word fits, but MANY/MUCH would on other letters.
