# B1 batch 4 review (letters J, K, L, M)

File `content/cards/B1/batch4.csv`. J and K are thin at true B1: most J/K cards are CONTAINS cards (e.g. MAJOR, REJECT, PACKAGE, NETWORK, TRACK), a deliberate hard-letter exception. J STARTS has only JAW, JEALOUSY, JEWEL, JET, JOINT, JUICY, JUNIOR, JUNK, JUSTICE; K STARTS only KINGDOM, KINDNESS.
Reviewer changes: KIDNAP and DRUNK dropped (sensitive); replaced by KINDNESS and TRICKY. Clues: LECTURE (vs LESSON), MANNER (vs METHOD). JUNIOR translation, MEANWHILE category.
Doubtful level: JOINT, JUSTICE, MASTER, JEALOUSY, LANDSCAPE, LITERATURE, MURDER (maybe B2); LATELY, LIVELY.
