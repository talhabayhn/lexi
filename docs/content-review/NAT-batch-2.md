# NAT batch 2 review (letters D, E, F)

File `content/cards/NAT/batch2.csv` (94 cards).
Own drops: same-letter near-synonyms (DENIGRATE/DISPARAGE vs DERIDE, DEMURE vs DIFFIDENT, EBULLIENT vs EXUBERANT, FACETIOUS vs FLIPPANT, THRIFTY vs FRUGAL); DEXTERITY, EXUBERANT, ERSTWHILE, EQUANIMITY moved to hard letters (X, W, Q) in later batches; rare words (DELETERIOUS, EDIFY, FETTER, FRACAS).
Reviewer fixes: clues that also fit a common same-letter word (DUBIOUS/DOUBTFUL, DEBACLE/DISASTER, DOGGED/DETERMINED, DELINEATE/DEFINE, DISGRUNTLED, DISCONCERTING/DISTURBING, DIRE, DEMISE/DECLINE, ELUCIDATE/EXPLAIN, EMBELLISH/EXAGGERATE, ELATED and EUPHORIA vs ECSTATIC, ERUDITE, FASTIDIOUS/FUSSY, FORTHRIGHT/FRANK, FOIBLE/FLAW, FRAUGHT/FULL, FRIVOLOUS, FLAMBOYANT, DEFT); FLUSTERED vs FLABBERGASTED separated; FRENETIC (= FRANTIC) replaced by FOREBODING, EFFICACY (= EFFECTIVENESS) by EPITAPH; DIGRESS, FOIBLE examples; DUPLICITY, FOOLHARDY translations.
Doubtful level: DUBIOUS, FUTILE, ELOQUENT, DEVOID (maybe C1).
