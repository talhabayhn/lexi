# Release notes 1.1.1

Covers changes in 1.1.1:
- Smoother first launch: pre-rolled splash animation and card flip / dialog warm-up.
- The daily gift notice on Home can now also be dismissed by swiping up (as well as tapping).
- Wider Android device compatibility: portrait screen orientation feature marked optional so landscape-only devices (tablets, Chromebooks, foldables) are not filtered out by Google Play.
