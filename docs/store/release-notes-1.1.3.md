# Release notes 1.1.3

Covers changes in 1.1.3:
- Fixed screens that could appear empty or freeze for a few seconds (fail-safe timeouts on all transitions and animations).
- Smoother transitions between screens.
- Category card flip now also plays with Low Power Mode on.
- Shadows appear together with their elements instead of lagging behind.
