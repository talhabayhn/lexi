# Release notes 1.1.2

Covers changes in 1.1.2:
- iOS: the category card flip now also plays with Low Power Mode on (Low Power Mode no longer switches the animations
  to the lighter version; only measured stutter does).
- Hard shadows of buttons and cards (PLAY, the dialog, the category cards, the game board) now fade in together with
  their element instead of appearing a moment later.
- Smoother first launch after installing or updating: the splash, the card flip, the dialog and the game board are
  prepared once, hidden, before the splash animation; later launches skip it.

Low Power Mode is iOS only, so the Play notes leave it out.
