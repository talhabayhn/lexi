## 3. Thin letters

- **Common letters under 40 (STARTS+CONTAINS)**: I, U, O, N, E, G, H at A1; U, W, N, G, I, O at A2–B2; G, H, L, M, N, T, U, W at C1/NAT.
- **Genuinely rare** (English has few words; use CONTAINS cards, lower target): Q (A1 only 5, all levels ≤ 21), X (STARTS 0 everywhere —
  CONTAINS only: BOX, TAXI, MIX …), Z (A1 5, B2 22 all CONTAINS), V, Y, J, K (A1 5–15).
- Worst gaps: A1 I/U/V/Y/Q/Z/X/O; C1 W/G/N/U/T; NAT L/N/O/T/U/W; B2 L/U/W/N/H.

## 6. Rules for every batch

- **AI drafts Turkish clues/examples; the OWNER reviews every batch** in `docs/content-review/<level>-batch-<n>.md`
  before merge. No batch ships unreviewed.
- **No proprietary lists**: do not copy Oxford 3000/5000 or Cambridge English Profile lists; use them only as a level reference (CONTENT.md §6).
- **Unique ids** `<level>-<answer>[-n]`, never reused or renamed; no duplicate answer within a level.
- **Ambiguity check** for every card: "could another word fit this clue and this letter?" If yes, rewrite the clue
  (near-synonyms get clearly different clues).
- **Blocklist** (`content/blocklist.txt`) and compiler validation (answer leak, example leak against all answers of the level,
  `pos` matches usage, clue ≤ 60 chars) must pass; QA without Gradle: `python3 tools/content-qa/qa.py`.
- **`contentVersion` bump** in `content/meta.json` once per release containing new cards.
- CEFR level follows the official A1–C1 label of the word; hard-letter exceptions are noted in the review sheet.
