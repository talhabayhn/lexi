## 5. Rules for every batch

- **AI drafts Turkish clues/examples; the OWNER reviews every batch** in `docs/content-review/<level>-batch-<n>.md`
  before merge. No batch ships unreviewed.
- **No proprietary lists**: do not copy Oxford 3000/5000 or Cambridge English Profile lists; use them only as a level reference (CONTENT.md §6).
- **Unique ids** `<level>-<answer>[-n]`, never reused or renamed; no duplicate answer within a level.
- **Keep the level**: do not pull words from the next level to fill a letter; a word that exists at another level is
  only reused when the owner agrees.
- **Example leak**: a new example must not contain another answer of its level, and a new answer must not appear in
  existing examples of its level (compiler/qa reports both).
- **Ambiguity check** for every card: "could another word fit this clue and this letter?" (CONTAINS cards: the same
  wheel letter). If yes, rewrite the clue.
- **Blocklist** (`content/blocklist.txt`) and validation (`python3 tools/content-qa/qa.py`, compiler in CI) must pass.
- **`contentVersion` bump** in `content/meta.json` once per release containing new cards.
