# Sample sources

Short excerpts (mono, 22.05 kHz, onset-aligned, tuned to equal temperament) cut by `../fetch_samples.py` from the
**Versilian Community Sample Library (VCSL)**, https://github.com/sgossner/VCSL, commit
`c1ea7bcc3c7309650ab0da9d15c9cd1fbc4a4c7e`.

License: **CC0 1.0 Universal** (public domain dedication) — free for commercial use, no royalties, no attribution
required. The source file of every excerpt is listed in `EXCERPTS` in `../fetch_samples.py`.

| Folder | Instrument |
|---|---|
| `piano/` | Upright Piano, Yamaha — sustain, softest velocity |
| `kalimba/` | Kalimba, Tanzania — pluck |
| `marimba/` | Marimba — soft mallets (outrigger) |
| `vibes/` | Vibraphone — soft mallets, softest velocity |
| `wood/` | Woodblock (pp), Slit Drum (log drum), Claves (pp) |
